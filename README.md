# Rental Price Tracker

MVP de suivi des prix de location.

## Fonctionnalités de cette version

- Lieu de prise en charge
- Date de début
- Heure de début
- Nombre de jours
- Calcul automatique de la date de retour
- Sélection du loueur
- Base prête pour l'historique des prix

## Déploiement Vercel

Le projet est configuré pour Next.js et Vercel.
